# NumPy Basics

Welcome to the **NumPy Basics** repository! This project includes a set of scripts showcasing the fundamental operations and capabilities of the NumPy library. It’s perfect for those learning Python and seeking to understand numerical computation.

## 🔧 Technologies and Tools Used

This project was developed using Python and includes:

1. **NumPy**: For numerical computations, including array manipulations, mathematical operations, and broadcasting.
2. **Python I/O**: For reading input and displaying results interactively.
3. **Jupyter Notebook (Optional)**: For an interactive coding and learning experience.

## 🌐 Program Overview

The scripts included in this repository cover:

- **Array Creation**: Demonstrating ways to create 1D, 2D, and multidimensional arrays using NumPy.
- **Mathematical Operations**: Performing basic and advanced arithmetic operations on arrays.
- **Broadcasting**: Understanding how NumPy handles operations between arrays of different shapes.
- **Indexing and Slicing**: Extracting and modifying specific elements, rows, or columns in arrays.
- **Statistical Functions**: Computing means, medians, sums, and other statistical measures.

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/notfawadmir/NumPy-Basics.git
   ```

2. Navigate to the repository folder and explore the scripts:

   ```bash
   cd NumPy-Basics
   ```

3. Run the scripts directly in your terminal or within a Jupyter Notebook:

   ```bash
   python numpy.py
   ```

4. Experiment with the code and customize it to deepen your understanding of NumPy.
